CS355: Programming Paradigms Lab (Autumn 2025)

Lab 1A: Introduction to Functional Programming with Scheme

⸻

Q0. Write a Scheme expression that prints your name and your roll number.

Q1. Write Scheme expressions for the following:
	•	a. 5 + 4 + (2 - (3 - (6 + 4/5)))
	•	b. 3(6 - 2)(2 - 7)/4
	•	c. (2 + 3)^2

Q2. Define the following functions:
	•	square: returns the square of a number
	•	mid: returns the middle of three distinct numbers
	•	abs-diff: returns the absolute difference of two numbers

Q3. Define the following recursive functions:
	•	sum-to-n: Returns the sum from 1 to n
	•	factorial: Returns n!

Q4. Write a recursive function count-digits that returns the number of digits in a positive integer. For example: (count-digits 12345) ; => 5
