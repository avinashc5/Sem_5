CS355: Programming Paradigms Lab (Autumn 2025)

Lab 1B: Introduction to Functional Programming with Scheme

⸻

Q0. Print a greeting with your name and your favourite food.

Q1. Write Scheme expressions for the following:
	•	7 + (3 * (10 - 4))
	•	((8 + 2)/(4 - 2)) * 5
	•	(6 - 3)^3

Q2. Define the following functions:
	•	cube: returns the cube of a number
	•	avg: returns the average of three numbers
	•	sign: returns 1 for positive, 0 for zero, -1 for negative

Q3. Define the following recursive functions:
	•	power: Computes a^b recursively
	•	product-to-n: Product from 1 to n

Q4. Write a cube-root function, similar to the square-root one from class, that computes the cube root of a number by average-damping a function that takes a number `y` and dampens the average of `y` and `x/y^2`.
